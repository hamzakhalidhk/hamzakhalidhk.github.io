# Hamza Khalid — Portfolio

A fast, responsive, accessible portfolio for GitHub Pages. Plain HTML, CSS, and JavaScript; no installation or build step.

## Local preview

Run `python3 -m http.server 8080` in this directory, then open `http://localhost:8080`.

## GitHub Pages

Publish the contents of this directory to the `main` branch of `hamzakhalidhk/hamzakhalidhk.github.io`. In Settings → Pages, select **Deploy from a branch**, `main`, and `/ (root)`. GitHub serves the site at https://hamzakhalidhk.github.io/.

## Editing

- `index.html`: biography, projects, experience, links, metadata.
- `styles.css`: responsive layouts, light/dark themes, reduced-motion and print styles.
- `script.js`: project filters, mobile menu, theme preference, copy email.
- `Hamza-Khalid-Resume.pdf`: supplied resume.
- `portrait.jpg`: public GitHub profile image.

Fonts are loaded from Google Fonts with system fallbacks. No tracking, analytics, API keys, backend, or runtime packages.
